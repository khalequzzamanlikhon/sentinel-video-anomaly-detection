# Data directory

- `raw/sample_clips/` — small synthetic clips (generated by `scripts/make_sample_clips.py`)
  used as the out-of-the-box demo sources in `config/cameras.yaml`. They're just moving
  rectangles: good for an I/O smoke test (capture, tracking IDs, dashboard), **not** for
  evaluating detection or anomaly accuracy. Replace with real footage of people for that, or
  point `cameras.yaml` at a webcam.
- `raw/` — otherwise intended for public CV datasets you download yourself (MOT17, MOT20,
  CrowdHuman, UCF-101, Kinetics-400 subset, UCSD Anomaly Detection, Avenue, UCF Crime). Not
  included in this repo (multi-GB, licensed for research use) -- see [../ROADMAP.md](../ROADMAP.md)
  for download links and how DVC tracking would work once you add them.
- `processed/` — frame extracts / preprocessed tensors derived from `raw/`, for training scripts.
- `annotations/` — your own labeled clips (e.g. via Label Studio) for fine-tuning the action
  classifier or building an anomaly test set.
- `alerts.db`, `clips/`, `thumbnails/` — created automatically at runtime by the alert pipeline;
  not committed (see `.gitignore`).
